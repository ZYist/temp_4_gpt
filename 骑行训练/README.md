# 骑行训练

本目录用于记录长沙→武汉春节骑行计划、训练安排、路线探索和复盘资料。

## 目录说明

- [`2027年春节长沙武汉骑行目标.md`](./2027年春节长沙武汉骑行目标.md)：总目标、训练能力门槛和安全红线。
- [`月度计划/`](./月度计划/)：按月制定训练主题、阶段目标和验收标准。
- [`周计划/`](./周计划/)：把月度目标拆成具体周末骑行与训练安排。
- [`骑行记录/`](./骑行记录/)：记录实际完成的骑行数据、补给、身体反馈和恢复情况。
- [`路线规划/`](./路线规划/)：记录路线方向、道路情况、补给点和危险路段。

## 计划与记录规则

1. 月度计划确定本月重点，但不锁死全部具体里程。
2. 周计划根据天气、身体状态、车辆状态和上一周完成情况动态调整。
3. 每次关键骑行结束后，在 `骑行记录/` 中保留实际路线、距离、耗时、补给、路况、身体反馈和恢复情况。
4. 计划是预期，实际骑行结果以复盘记录为准；未完成目标时记录原因，不通过冒险补偿里程。
5. 天气、身体、车辆或交通安全不满足条件时，取消或缩短计划。
6. 达成阶段目标后优先安排恢复和问题修正，不为了计划表继续机械增加里程。
