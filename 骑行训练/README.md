# 骑行训练

本目录用于记录长期骑行训练、长沙→武汉路线探索、多日骑行旅行规划和实际复盘资料。

## 当前长期方向

2026 年 9 月 12～13 日完成长沙→岳阳方向连续两日长途训练后，原“2027 年春节长沙→武汉骑行返乡”目标已调整。

当前方向为：

- 继续提高心肺能力和骑行效率；
- 维持长距离能力，不以持续刷新极限里程为主；
- 重点优化手部压力、防晒、高温散热、睡眠和补给携带；
- 长沙→武汉保留为未来长假休闲骑行项目；
- 推荐单程约 100～120 km／天，分 3～4 天骑到武汉，再乘火车返回长沙；
- 不再绑定 2027 年春节，也不再以春节往返为训练验收目标。

详细见：[`长期骑行训练与旅行目标.md`](./长期骑行训练与旅行目标.md)。

## 目录说明

- [`长期骑行训练与旅行目标.md`](./长期骑行训练与旅行目标.md)：当前长期训练方向和未来骑行旅行目标。
- [`2027年春节长沙武汉骑行目标.md`](./2027年春节长沙武汉骑行目标.md)：原春节返乡目标，已归档保留历史记录。
- [`月度计划/`](./月度计划/)：按月制定训练主题、阶段目标和验收标准。
- [`周计划/`](./周计划/)：根据月度目标和恢复情况拆分具体训练安排。
- [`骑行记录/`](./骑行记录/)：记录实际完成的骑行数据、补给、身体反馈和恢复情况。
- [`路线规划/`](./路线规划/)：记录路线方向、道路情况、补给点和危险路段。

## 计划与记录规则

1. 月度计划确定本月重点，但不锁死全部具体里程。
2. 周计划根据天气、身体状态、车辆状态和上一周完成情况动态调整。
3. 每次关键骑行结束后，在 `骑行记录/` 中保留实际路线、距离、耗时、补给、路况、身体反馈和恢复情况。
4. 计划是预期，实际骑行结果以复盘记录为准；未完成目标时记录原因，不通过冒险补偿里程。
5. 天气、身体、车辆或交通安全不满足条件时，取消或缩短计划。
6. 达成阶段目标后优先安排恢复和问题修正，不为了计划表继续机械增加里程。
7. 长距离能力建立后，训练重点逐步转向心肺、效率、舒适性和安全性，而不是继续堆叠极限距离。
