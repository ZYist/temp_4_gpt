# 2027年春节长沙→武汉骑行目标

## 目标

2027年春节假期，从长沙骑行返回武汉。

策略：

- 安全优先，不追求极限。
- 预计路线约400km。
- 沿途补给方便，因此采用轻装骑行模式。
- 若天气、身体、车辆或训练能力不满足条件，则取消骑行计划。

## 当前基础（2026年9月）

- 已完成79.61km长途骑行。
- 实际骑行时间：4小时22分37秒。
- 平均速度：18.1km/h。
- 累计爬升：579m。
- 骑完后恢复良好，次日可正常通勤。
- 当前主要需要优化：补给习惯、手部和颈肩舒适性、长时间骑行适应。

## 训练方式

采用滚动规划：

- 每月开始制定当月目标。
- 当月内拆分为周计划。
- 根据实际完成情况调整下个月计划。

不提前锁死春节前全部训练内容。

## 2026年9月目标

主题：建立可靠100km能力。

目标：

1. 完成第一次100km骑行。
2. 测试补给方案。
3. 测试骑行装备。
4. 开始探索长沙→武汉方向路线。

## 本阶段重点

- 长距离骑行优先于速度训练。
- 周末长骑同时作为路线侦察。
- 记录道路情况、补给点、危险路段。

## 安全红线

1. 天气风险：出现雨雪、冻雨、结冰、大雾、强风等情况，取消计划。
2. 身体或事故风险：出现影响安全骑行的问题，立即停止推进。
3. 能力风险：训练结果无法达到返乡需求，则重新评估计划。
