## 记录原则

1. 原始饮食尽量保留实际食品、重量和营养标签数据。
2. 没有称重或没有营养标签的食物，只做区间估算，不伪造精确值。
3. 体重只记录实际测量值，并优先看 7 日平均而非单日波动。
4. 肚围测量标准：自然放松，水平绕过肚脐；主要看 2～4 周趋势。
5. 力量训练记录动作、组数、次数、动作难度／高度及主观疲劳。
6. 骑行尽量补充距离、总时长、实际训练时长、平均心率／主观强度（如有）。
7. 每日蛋白质优先观察长期平均，当前实用目标约 120～140 g／天。
