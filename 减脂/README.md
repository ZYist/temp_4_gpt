# 减脂／训练长期记录

本目录用于维护饮食、训练、体重、围度、恢复和减脂阶段复盘。

## 目录职责

- [`模板/每日记录模板.md`](./模板/每日记录模板.md)：新建每日记录时复制的统一模板。
- [`模板/周报模板.md`](./模板/周报模板.md)：每周复盘时复制的统一模板。
- [`每日记录/`](./每日记录/)：每日原始事实的唯一正式来源，按 `YYYY-MM-DD.md` 命名。
- [`周报/`](./周报/)：按周汇总趋势、执行情况和调整计划，不替代每日原始记录。
- [`体重与围度记录.md`](./体重与围度记录.md)：长期体重／围度测量表，只记录测量事实和长期趋势。
- [`常用食物.md`](./常用食物.md)：反复出现且配方固定的食物定义和营养标签。

## 当前长期目标

- 身高：175 cm
- 减脂起点：约 2026-02-28
- 目标体重：80 kg
- 主要目标：改善整体视觉和运动表现，同时尽量保留／提升力量
- 日常工作：程序员，久坐为主

当前体重和围度以 [`体重与围度记录.md`](./体重与围度记录.md) 的最新测量为准，不在本 README 中重复维护动态数据。

## 当前训练框架

- 周一：全身力量训练
- 周二：拳击或额外骑行
- 周三：恢复／娱乐
- 周四：全身力量训练
- 周五：拳击／轻骑／休息
- 周六：长途骑行
- 周日：完全休息
- 工作日通勤骑行：正常保留，不计作正式训练课

## 记录规则

1. 每日记录保存原始事实：实际测量、实际饮食、实际训练和实际身体反馈。
2. 每日记录统一使用 [`每日记录模板.md`](./模板/每日记录模板.md) 的标题结构；没有发生或没有记录时，明确写“无”“不适用”或“尚未记录”。
3. 营养估算单独放在“营养估算”部分，区分包装标签、实际称重和区间估算，并标注可信度。
4. “当日复盘”只记录观察、问题和后续计划，不把推测写成事实。
5. 每日记录是单日事实的唯一来源；周报和长期汇总只引用、概括，不反向复制完整内容。
6. `体重与围度记录.md` 只维护长期测量表；新增体重或围度后，再同步更新对应表格。
7. 肚围测量标准：自然放松，水平绕过肚脐；主要观察 2～4 周趋势。
8. 体重优先观察 7 日平均，不根据单日波动直接判断脂肪变化。
9. 每日蛋白质优先观察长期平均，当前实用目标约 120～140 g／天。
10. 未称重或没有营养标签的食物只做区间估算，不伪造精确值。

## 新增记录流程

1. 复制 `模板/每日记录模板.md`，重命名为 `每日记录/YYYY-MM-DD.md`。
2. 先填写体重、围度、饮食和训练等事实，再填写营养估算和复盘。
3. 记录完成后，将新的体重／围度测量同步到 `体重与围度记录.md`。
4. 每周结束后复制 `模板/周报模板.md`，在 `周报/` 中建立对应周报。
