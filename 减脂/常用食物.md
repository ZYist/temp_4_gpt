# 常用食物与营养参考

本文件用于记录饮食日志中反复出现的食物、包装标签和固定参考分量。它不是医疗或营养诊断依据；除非特别标注，数值均为估算值。

## 使用规则

1. **包装标签优先。** 用户提供的包装营养标签按实际包装规格计算，可信度通常高于通用食物数据库。
2. **标签不完整时不反推。** 只有能量和蛋白质时，碳水、脂肪和钠写“未提供”，不根据剩余热量强行推算。
3. **参考估算不等于实测。** 鸡蛋、虾、水果和蔬菜会受大小、品种、可食部分、生熟状态影响，适合用于日常粗略记录，不适合写成精确值。
4. **重量口径要写清楚。** 固体优先记录可食部分的 `g`，液体使用 `ml`；带壳、带骨或宰杀前重量不能直接等同于可食重量。
5. **实际分量不同要覆盖默认值。** 品牌、配方或分量改变时，以当天记录为准，并注明变化。
6. 能量统一换算为 kcal，换算关系为：`1 kcal ≈ 4.184 kJ`。

## 可信度分级

- **高：** 来自当前使用产品的包装标签，或由标签和实际分量直接计算。
- **中：** 常见食物的通用参考值，适合日常估算，但会因食材大小和可食部分变化。
- **低：** 只有部分标签信息，或份量、品牌、配方和可食部分不明确；仅作宽泛参考。

- 普通纯牛奶的能量和蛋白质；
- 全麦面包的能量、蛋白质、脂肪、碳水、膳食纤维和钠；
- 蔓越莓贝果的能量、蛋白质、脂肪、碳水和钠；
- 饭团的能量和蛋白质；
- 去皮鸭腿的整包营养成分。

这些数据来自包装标签，或由包装标签按实际分量直接换算。前提是品牌和规格没有变化。

### 可以作为粗略参考

- 水煮蛋、白灼虾、香蕉、西红柿、生菜、芹菜、苦菊和香菇。

这些食物的参考数值整体具有日常使用价值，但应该保留“约”“区间”或“很低”等不确定性表达。虾尤其要注意记录的是可食部分还是带壳重量。

### 暂不建议固定使用的部分

- 包装标签未提供的牛奶和饭团的碳水、脂肪、钠；
- 09-09 记录中的“原切燕麦 50 ml”，因为没有重量，不能直接按 50 g 计算；
- 没有品牌、规格或可食部分说明的外卖和熟食。
