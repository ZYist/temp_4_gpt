# temp_4_gpt

这是一个用于存放个人资料、训练记录、路线计划、临时材料和脚本的仓库。

## 目录说明

- [`减脂/`](./减脂/)：体重、围度、饮食、训练和恢复记录。
- [`骑行训练/`](./骑行训练/)：2027 年春节长沙→武汉骑行目标、月度／周计划、路线规划和复盘资料。
- [`脚本/`](./脚本/)：用户脚本等可复用脚本文件。
- [`临时/`](./临时/)：网页版临时存放短期文件的目录。

## 减脂记录入口

- [减脂目录说明](./减脂/README.md)
- [每日记录模板](./减脂/模板/每日记录模板.md)
- [周报模板](./减脂/模板/周报模板.md)
- [体重与围度汇总](./减脂/体重与围度记录.md)

每日事实写入 `减脂/每日记录/YYYY-MM-DD.md`；长期测量写入 `体重与围度记录.md`；每周复盘写入 `减脂/周报/`。模板只作为复制来源，不直接在模板文件中填写真实数据。

## 临时目录规则

`临时/` 只用于短期周转，不作为正式资料归档位置。临时文件确认不再使用后应及时删除，或迁移到合适的主题目录，并尽量使用清晰的文件名和日期。

请不要在公开仓库中放置密码、令牌、个人身份信息或未准备公开的文件。文件进入 Git 历史后，删除当前文件并不等于从历史中彻底清除。

## 隐私说明

本仓库目前为公开仓库。`减脂/` 中包含个人体重、围度、饮食、补剂和训练信息；如果这些内容不适合公开，应将仓库改为私有，或迁移到私有仓库后再继续记录。
